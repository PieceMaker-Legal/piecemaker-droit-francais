Accès Légifrance et Judilibre

PieceMaker interroge directement les bases officielles Légifrance (textes) et Judilibre (jurisprudence de la Cour de cassation et des juridictions). L'État les ouvre gratuitement par le portail PISTE, avec des identifiants personnels. Comptez une dizaine de minutes ; chaque bouton ouvre la bonne page dans votre navigateur.

  1. 1. Compte PISTE
  2. 2. Conditions d'utilisation
  3. 3. Application
  4. 4. Identifiants

Créez votre compte PISTE

  1. Renseignez votre nom et votre adresse e-mail : elle deviendra votre identifiant PISTE.
  2. Choisissez un mot de passe d'au moins 12 caractères avec une majuscule, une minuscule, un chiffre et un caractère spécial parmi ! @ # ^ + ( ) , ; . ? : { } | _ § ~.
  3. Laissez « Code de l'organisation » vide : vous serez rattaché à l'organisation « Universelle », qui donne accès à Légifrance et à JUDILIBRE.
  4. Cochez « J'accepte les termes des CGU », passez la vérification de sécurité, puis cliquez sur « S'inscrire ».
  5. Ouvrez l'e-mail envoyé par PISTE et cliquez sur le lien d'activation, puis connectez-vous.

Vous avez déjà un compte PISTE ? et passez à l'étape 2.

Acceptez les conditions d'utilisation de Légifrance et JUDILIBRE

Sans cette acceptation, PISTE grise les cases de ces deux API à l'étape suivante.

  1. Dans le champ « Recherche », tapez Légifrance et cochez la ligne dont l'environnement est PROD.
  2. Recommencez avec JUDILIBRE et cochez sa ligne PROD.
  3. Cliquez sur « Valider mes choix CGU ».

Créez l'application de production « PieceMaker »

  1. Cliquez sur « Créer une application », laissez l'environnement PRODUCTION, puis cliquez sur « Créer l'application ».
  2. Remplissez au minimum : Nom de l'application PieceMaker, votre e-mail, Information sur la structure (le nom de votre cabinet) et Responsable d'application (votre nom).
  3. Dans « Sélectionner les API », cochez la colonne « Souscrite » pour JUDILIBRE et pour Légifrance. Si une case est grisée, revenez à l'étape 2.
  4. Enregistrez l'application.

Ne prenez pas l'application « APP_SANDBOX_… » créée automatiquement : c'est un bac à sable, ses identifiants ne fonctionnent pas avec les vraies bases.

Copiez vos identifiants dans PieceMaker

  1. Dans , cliquez sur le nom de votre application PieceMaker.
  2. Dans la section « Identifiants Oauth », copiez le Client ID et collez-le ci-dessous.
  3. Cliquez sur « Consulter le secret », copiez le Client Secret et collez-le ci-dessous.
