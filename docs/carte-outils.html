Index

L'index est une tabular review à part. tabular_review_index reprend ses sous-commandes et déduit le fichier et le projet. L'index s'affiche toujours dans l'onglet Dossier, jamais dans le volet Tabular Review. tabular_review refuse son fichier et son projet.

CommandeEffetLit les pièces
pm afficher --volet indexOuvre l'onglet Index du volet Dossier.non
pm tabular_review_index ouvrirRetrouve ou prépare l'unique analyse de toutes les pièces, puis l'ouvre dans l'onglet Dossier.oui, au lancement
pm tabular_review_index preparer|lancer|lire|colonnes|classement|arborescence|relancerMêmes actions que tabular_review, sur l'index. Le résultat s'ouvre dans l'onglet Dossier.oui, à lancer et relancer
pm tabular_review_index lister|modifierLit ou modifie les dates et les libellés des pièces en base.non

Volets de l'interface

Ces plugins servent l'avocat. Leurs manifestes ne déclarent aucun outil IA. Le moteur ouvre Dossier, Analyse tabulaire et Bordereau avec pm afficher. L'index est un onglet du volet Dossier, pas un plugin.

Maintenance

Mettez à jour cette carte quand un outil, un skill ou une commande change, puis republiez l'artefact.

  • Outils : mcp_definitions.py, server.mjs, pm.mjs.
  • Skills : les SKILL.md, server/piecemaker/skill-declaration.ts.
  • MCP par dossier : server/piecemaker/mcp-declaration.ts.
  • Binaire : docx --help.
