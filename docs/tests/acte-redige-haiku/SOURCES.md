# Textes disponibles (recherche Légifrance du dossier)

Chaque texte : identifiant, intitulé, période de vigueur, texte intégral.

- LEGIARTI000000000101 — Code civil, article 1103 — en vigueur depuis le 2016-10-01 : « Les contrats légalement formés tiennent lieu de loi à ceux qui les ont faits. »
- LEGIARTI000000000102 — Code civil, article 1219 — en vigueur depuis le 2016-10-01 : « Une partie peut refuser d'exécuter son obligation, alors même que celle-ci est exigible, si l'autre n'exécute pas la sienne et si cette inexécution est suffisamment grave. »
- LEGIARTI000000000105 — Code civil, article 1353 — en vigueur depuis le 2016-10-01 : « Celui qui réclame l'exécution d'une obligation doit la prouver. Réciproquement, celui qui se prétend libéré doit justifier le paiement ou le fait qui a produit l'extinction de son obligation. »
- LEGIARTI000000000103 — Code de commerce, article L. 441-10 — en vigueur depuis le 2019-04-26 : « Tout professionnel en situation de retard de paiement est de plein droit débiteur, à l'égard du créancier, d'une indemnité forfaitaire pour frais de recouvrement, dont le montant est fixé par décret. »
- LEGIARTI000000000104 — Code de commerce, article D. 441-5 — en vigueur depuis le 2019-04-26 : « Le montant de l'indemnité forfaitaire pour frais de recouvrement prévue au II de l'article L. 441-10 est fixé à 40 euros. »
- LEGIARTI000000000106 — Code de commerce, article L. 110-4 — en vigueur depuis le 2008-06-19 : « Les obligations nées à l'occasion de leur commerce entre commerçants ou entre commerçants et non-commerçants se prescrivent par cinq ans si elles ne sont pas soumises à des prescriptions spéciales plus courtes. »
- LEGIARTI000000000107 — Code civil, article 2224 — en vigueur depuis le 2008-06-19 : « Les actions personnelles ou mobilières se prescrivent par cinq ans à compter du jour où le titulaire d'un droit a connu ou aurait dû connaître les faits lui permettant de l'exercer. »
