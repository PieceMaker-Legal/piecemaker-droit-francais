# Dossier test — indemnité de départ d'un directeur général

Corpus entièrement fictif. Les six pièces sont créées pour un essai de raisonnement et n'ont aucune valeur officielle. Elles ne proviennent d'aucun dossier réel. Le numéro d'immatriculation nul est un marqueur de test et ne doit pas être recherché comme une entreprise réelle.

## Mission

Vous défendez Jean Dupont contre Société Exemple SA. Le dossier est contentieux. L'objectif est d'obtenir le paiement de l'indemnité de départ de 480 000 euros bruts réclamée par Jean Dupont. Le dossier est confié au conseil le 21 octobre 2026. Aucune procédure judiciaire ni transaction antérieure n'est signalée.

Les pièces fournies constituent le corpus initial. Rechercher le droit utile, traiter les moyens adverses et transcrire le raisonnement dans le format actuel de PieceMaker. Un fait ou un acte qui n'est pas dans les pièces ne doit pas être ajouté comme s'il existait.

Les documents sont en Markdown pour être directement lisibles. La pièce 1 comporte une annexe distincte sur la cotation ; elle ne fait pas passer cette information pour une mention du Kbis.
