# New Style

1° Pars du docx de travail produit dans la session & le fil de la session uniquement (ne rien inventer, partir uniquement de ces deux sources). 

2° Copier le docx de travail dans templates et en faire un template puis le nommer <type d acte>.docx : conserver les formules / titres génériques, supprimer ce qui est particulier à l'acte, remplacer les entités par des placeholders. 

3° Créer un fichier style <type d acte>.md Repérer les particularités de l'acte. Intégrer dans styles quelques exemples de rédaction (un ou deux paragraphes). Ne jamais lister les règles de droit, décrire uniquement la forme. 
Ne pas créer de doublon avec citations.md.
